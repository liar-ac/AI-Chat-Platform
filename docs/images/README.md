# Project Screenshots

This directory contains screenshots of the AIFriends application for documentation purposes.

## Recommended Files

| File | Description |
|------|-------------|
| `home.png` | Homepage — character grid with infinite scroll |
| `chat.png` | AI chat — streaming dialogue with voice playback |
| `blog.png` | Blog square — card grid with cover images |
| `create-character.png` | Character creation — form with avatar, voice, background |

## How to Take Screenshots

1. Start the project locally (see root README.md)
2. Open http://localhost:8000/ in your browser
3. Navigate to each page and take a screenshot
4. Save the screenshot with the recommended filename above
5. Commit the images to this directory

## Notes

- Use PNG format for best quality
- Recommended width: 1280px or 1440px
- Remove any personal data (API keys, usernames, passwords) before committing
